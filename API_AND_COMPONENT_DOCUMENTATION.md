## AI Shopping Assistant — API & Component Documentation

### Overview
This repository contains a Streamlit app (`shop_partener_revised_streamlit.py`) that collects shopping preferences, uses an LLM agent with web search to find products, renders results as a table, and optionally exports them as a Word document.

### Quickstart
- **Install dependencies**:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

- **Set required environment variables**:
  - **`SERPER_API_KEY`**: required for web search via `SerperTools`.
  - **OpenAI credentials**: required for `OpenAIChat`. The exact variable name depends on your OpenAI/Agno setup (commonly `OPENAI_API_KEY`).

Example:

```bash
export SERPER_API_KEY="..."
export OPENAI_API_KEY="..."
```

- **Run the app**:

```bash
streamlit run shop_partener_revised_streamlit.py
```

### Public APIs (Module-Level Functions)
All functions below live in `shop_partener_revised_streamlit.py`.

#### `setup_agent() -> agno.agent.Agent`
Creates (and Streamlit-caches) the recommendation agent.

- **What it does**:
  - Uses `OpenAIChat(id="gpt-4o")` as the model.
  - Enables real-time web search through `SerperTools()`.
  - Applies a fixed set of instructions emphasizing trusted stores, availability, and clearly formatted recommendations.

- **Caching behavior**:
  - Decorated with `@st.cache_resource`, so the agent instance is reused across reruns.

- **Example (programmatic use)**:

```python
from shop_partener_revised_streamlit import setup_agent

agent = setup_agent()
result = agent.run("Recommend 3 blue running shoes under Rs. 10000")
print(getattr(result, "content", str(result)))
```

#### `parse_response_to_table(response_text: str) -> pandas.DataFrame`
Parses a plain-text agent response into a structured `pandas.DataFrame`.

- **Expected response format** (repeated per product):

```text
1. Product title
   - Price: ₹12,345
   - Fabric: Some fabric
   - Features: Some features
   - Link: [View on Amazon](https://example.com/item)
```

- **Output schema**:
  - **`Product`**
  - **`Price (₹)`**
  - **`Fabric`**
  - **`Features`**
  - **`Store`** (e.g., Amazon, Flipkart)
  - **`Link`**

- **Notes / limitations**:
  - Parsing is regex-based; if the agent output deviates from the expected format (different bullet labels, missing “Fabric”, different link text, etc.), the returned DataFrame will be empty.
  - Price is captured as digits/commas/periods following the rupee symbol.

- **Example**:

```python
from shop_partener_revised_streamlit import parse_response_to_table

text = """1. Example Shoe\n   - Price: ₹9,999\n   - Fabric: Mesh\n   - Features: Lightweight, breathable\n   - Link: [View on Amazon](https://example.com)"""

df = parse_response_to_table(text)
print(df)
```

#### `generate_docx_from_df(df: pandas.DataFrame) -> io.BytesIO`
Exports a DataFrame into a Word document with a heading and a grid table.

- **Output**:
  - Returns an in-memory `BytesIO` buffer positioned at the start, suitable for Streamlit downloads.

- **Example (saving to disk)**:

```python
from shop_partener_revised_streamlit import generate_docx_from_df
import pandas as pd

df = pd.DataFrame([
    {"Product": "Example", "Price (₹)": "9999", "Fabric": "Mesh", "Features": "Lightweight", "Store": "Amazon", "Link": "https://example.com"}
])

buf = generate_docx_from_df(df)
with open("product_recommendations.docx", "wb") as f:
    f.write(buf.getvalue())
```

### UI Components (Streamlit)
The app is defined at module import time (i.e., running the script via Streamlit executes the UI code).

#### Page configuration
- `st.set_page_config(page_title="🛍️ AI Shopping Assistant", layout="centered")`

#### Inputs (form: `product_form`)
- **Product Category** (`st.text_input`, default: `Sports shoe`)
- **Preferred Color** (`st.text_input`, default: `Blue`)
- **Purpose** (`st.text_input`, default: `Comfortable for long-distance running`)
- **Max Budget (INR)** (`st.text_input`, default: `10000`)

#### Action
- **Get Recommendations** button triggers:
  - Agent creation via `setup_agent()`
  - Query construction from the form inputs
  - `agent.run(query)`
  - Markdown bold cleanup (`**...**` stripped)
  - Attempted structured parsing with `parse_response_to_table()`

#### Outputs
- If parsed table is non-empty:
  - Displays `st.dataframe(df, use_container_width=True)`
  - Provides `st.download_button` to download `product_recommendations.docx` generated by `generate_docx_from_df(df)`
- If parsing fails:
  - If the raw text looks like recommendations (contains keywords like “here are some”, “options”, “suitable”), it displays the text via `st.markdown`.
  - Otherwise shows `st.info("No product recommendations were found.")`

### Operational Notes
- **Network access**: web search + model calls require outbound connectivity.
- **Security**: never commit API keys; use environment variables.

### Troubleshooting
- **Empty table**:
  - The agent output likely didn’t match the expected format used by `parse_response_to_table`.
  - In that case, the UI may fall back to displaying the raw text instead of a table.
- **Search failures**:
  - Confirm `SERPER_API_KEY` is set and valid.
- **Model failures**:
  - Confirm OpenAI/Agno credentials are configured (commonly `OPENAI_API_KEY`).
